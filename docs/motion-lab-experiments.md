# Interactive Motion Lab

Open a fresh factory copy with `?lesson=motion-lab`. Existing saved copies are
preserved. The new interactive section follows the eight design examples.

On any content slide, select **Look → Motion experiment** and **Experiment
style**. Labels and explanations use the existing points, separated by a tab.
Up to four points are displayed. Image specimens use the image path in Look.
Present activates controls; static views show a settled overview.

| Experiment | Controls |
| --- | --- |
| Circular image mask | Transformation slider, Next/Previous in quarter steps |
| Draw-on connections | Next/Previous reveal nodes and trace connectors |
| Card to detail | Select card to expand; Return to overview |
| Image annotations | Next/Previous reveal numbered callouts at fixed relative positions |
| Circle-to-bar transformation | Scrub 0–100; each point explanation supplies a positive value up to 100 |
| Cause and effect | Input slider for y = ax; multiplier editable in Look |
| Branching scenario | Select response to reveal its authored consequence; return and try another |
| Exploded system | Separation slider plus selectable component descriptions |
| Focus lens | Pointer drag or two keyboard-accessible position sliders |
| Story panels | Select a panel to expand while retaining neighbouring context |

All ten offer Reset / replay. State uses the existing Explore presenter channel
and is kept out of saved slide content. Five styles are available: editorial,
layered paper, technical drawing, cinematic depth, and comic panels.

These are experimental browser-native presets. Card expansion stays within a
slide; branching does not navigate a deck or accept automatic audience votes.
Annotations have fixed relative anchors, not a general arrow/blur editor.
Exploded components are 2D panels, not a 3D model. The lens magnifies the same
image. Chart transition frames are explanatory shapes, not additional data.
The linear model is illustrative. Reduced motion removes eased animation.
Static exports retain the content overview; live interaction requires Present.
